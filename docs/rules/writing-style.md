# 문체 규칙

한국어로 쓰는 모든 글은 **문어체**로 쓰고, 구어체는 쓰지 않는다. 대상은 다음과 같다.

- 사이트 문구: `src/lib/translations/` 의 ko 문자열, `index.html` 의 `<title>`·메타 태그
- 데모 목업: `src/components/mocks/*.tsx` 의 `COPY.ko` 문자열과 예시 데이터(코멘트, 위키 본문, 설명 등)
- 문서: `README.md`, `docs/` (플랜 포함)
- 코드·CSS 주석

영어 문구(en)는 이 규칙의 대상이 아니다.

## 1. 종결

| 대상                             | 종결                                                                      |
| -------------------------------- | ------------------------------------------------------------------------- |
| 사이트·목업의 설명문·안내문      | 합니다체 `~합니다`·`~입니다`·`~됩니다`                                    |
| 독자에게 행동을 요청하는 문장    | 하십시오체 `~하십시오`·`~해 주십시오`                                     |
| 질문(FAQ, 대화상자 제목)         | `~합니까?`·`~하시겠습니까?`                                               |
| 헤드라인·키커·버튼·탭·배지·표 칸 | 명사형·체언 종결 허용(`센서 신호에도 라벨을.`, `무료로 시작`, `구독하기`) |
| 입력란 placeholder               | 명사형(`답글 입력…`, `동영상 검색…`)                                      |
| 문서, 코드·CSS 주석              | 평서형 `~한다`·`~이다`. 목록·표 칸에서는 명사형(`~함`, `~ 금지`)도 허용   |

- 해요체(`~해요`, `~돼요`, `~할게요`, `~이에요`)는 쓰지 않는다.
- `~세요` 계열(`~하세요`, `~해 주세요`, `~해 보세요`)도 쓰지 않는다. app.cvp.run 의 문체 규칙은 UI 문자열에
  `~하세요` 를 허용하지만, 이 사이트는 허용하지 않는다.
- 요청문은 평서문으로 바꿀 수 있으면 평서문을 우선한다(`업그레이드하세요` → `업그레이드할 수 있습니다`,
  `받아보세요` → `이메일로 전해 드립니다`). 꼭 요청해야 하면 하십시오체를 쓴다(`다시 시도해 주십시오`).
- 확인 질문은 `~할까요?`·`~나요?` 대신 `~하시겠습니까?`·`~합니까?` 로 쓴다
  (`어떤 파일을 올리나요?` → `어떤 파일을 업로드하시겠습니까?`).
- 반말(`~거든`, `~잖아`, `~지?`)과 청유형(`~하자`, `~합시다`)은 쓰지 않는다.
- 감탄 부호 `!` 는 쓰지 않는다.
- 설명문은 완결된 문장으로 끝낸다. 체언·조사로 끝나는 문장(`~한곳에서.`, `~작업자까지.`)은 헤드라인·표 칸에만
  쓴다(`… 팀의 비전 데이터 전부를 한곳에서.` → `… 하나의 워크스페이스에서 관리합니다.`).
- 링크 버튼은 `~ 자세히` 로 끊지 않고 `~ 자세히 보기` 로 쓴다.

## 2. 축약하지 않는다

| 구어      | 문어          |
| --------- | ------------- |
| 건        | 것은          |
| 게        | 것이          |
| 걸        | 것을          |
| 거        | 것            |
| 뭘 · 뭐   | 무엇을 · 무엇 |
| 이거·그거 | 이것·그것     |
| 얘기      | 이야기        |
| 땐 · 엔   | 때는 · 에는   |

## 3. 구어 어휘를 쓰지 않는다

| 구어                       | 문어(문맥에 맞게 선택한다)                 |
| -------------------------- | ------------------------------------------ |
| 그냥                       | 그대로, 별도 처리 없이, 단순히 (또는 생략) |
| 진짜                       | 실제, 실제로                               |
| 좀                         | 조금, 다소                                 |
| 근데 · 그럼                | 그런데 · 그러면                            |
| 어차피                     | 결국, 어느 경우든, 이미                    |
| 엄청 · 되게 · 완전(부사)   | 매우 · 매우 · 완전히(관형어는 `완전한`)    |
| 대충 · 쭉                  | 대략 · 계속                                |
| 딱 · 싹 · 확               | 정확히 · 모두 · 크게                       |
| 공짜                       | 무료                                       |
| 덤으로                     | 부수적으로, 추가로                         |
| 왜냐면                     | 왜냐하면                                   |
| 살짝 · 일단 · 금방         | 약간 · 우선 · 곧·빠르게                    |
| 랑 · 이랑 · 하고(나열)     | 와 · 과                                    |
| 한테                       | 에게                                       |
| 내 GPU·내 에이전트·내 장비 | 자체 GPU·자체 에이전트·자체 장비           |

| 쓰다 · 쓰이다            | 기능·토큰·값           | 사용하다 · 사용되다           |
| 바꾸다 · 바뀌다          | 설정·값·상태·주소      | 변경하다 · 변경되다, 대체하다 |

| 찍다                     | 로그·콘솔              | 출력하다, 기록하다            |

## 5. 목업 문자열

목업은 app.cvp.run 화면의 배치와 용어(메뉴, 탭, 버튼, 상태 이름)를 그대로 따르되, 문장 문자열은 이 규칙을 따른다.
앱 원문이 구어체이면 의미를 유지한 채 문어체로 고쳐 쓴다.

| 앱 원문                                       | 목업                                          |
| --------------------------------------------- | --------------------------------------------- |
| `이 프로젝트에 연결된 에이전트를 관리하세요.` | `이 프로젝트에 연결된 에이전트를 관리합니다.` |
| `어노테이션에 대한 의견을 남겨주세요…`        | `어노테이션에 대한 의견 입력…`                |
| `부팅 시 자동으로 뜨도록`                     | `부팅 시 자동으로 실행되도록`                 |

## 6. 바꾸지 않는 것

- **표준어 뜻으로 쓴 말**: 핀을 `꽂다`, 자막·챕터를 `달다`, 겹쳐 `보다`, `돌려주다`·`되돌리다`·홈으로 `돌아가다`.
- **인용**: 사용자 지시 원문(플랜의 "사용자 지시" 인용), 외부 문서·제품 문구 인용.
- **고유명사·코드 식별자·명령어**.

## 7. 점검

새 문구를 추가하거나 고친 뒤 아래 명령의 출력이 비어 있는지 확인한다.

```shell
git grep -nP '(해요|돼요|세요|어요|아요|예요|에요|게요|까요|나요|네요|죠)(?![가-힣])' \
  -- src index.html README.md docs ':!docs/rules/writing-style.md'
```

출력이 비어 있어도 2~4절의 축약·구어 어휘·동사는 정규식으로 모두 잡히지 않으므로, 바꾼 문장을 직접 읽고 확인한다.
