## 1. 개요

CVP(이하 "본 서비스")는 사용자의 개인정보 보호를 중요하게 생각합니다. 본 개인정보처리방침은 본 서비스가 수집하는 정보와 그 사용 방법에 대해 설명합니다.

## 2. 수집하는 정보

본 서비스는 데스크톱 애플리케이션으로서 다음과 같은 정보를 처리합니다:

- **로컬 파일**: 사용자가 직접 열거나 처리하는 이미지 및 비디오 파일
- **설정 정보**: 애플리케이션 사용 환경설정 (로컬에 저장)

## 3. 정보의 사용

수집된 모든 정보는 사용자의 로컬 컴퓨터에서만 처리되며, 외부 서버로 전송되지 않습니다.

## 4. 정보의 공유

본 서비스는 사용자의 개인정보를 제3자와 공유하지 않습니다.

## 5. 데이터 보안

모든 데이터는 사용자의 로컬 환경에서 처리되므로, 데이터 보안은 사용자의 시스템 보안에 의존합니다.

## 6. 문의

본 개인정보처리방침에 대한 문의사항이 있으시면 GitHub Issues를 통해 연락해 주세요.
